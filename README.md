# PEP 小学英语单词记忆与复习

这是一个纯前端、无需服务器的学习网站。

## 发布到网络
推荐 GitHub Pages：
1. 在 GitHub 新建一个仓库，例如 `pep-english-practice`
2. 上传 `index.html`
3. 在仓库 Settings → Pages 中选择从主分支发布
4. 等待发布完成后即可获得网页地址。

## 重要说明
当前版本先放入少量“示例词”用于验证网站功能。
由于 PEP 教材存在不同年份/版本，正式使用前应根据你手中的教材逐年级、逐册、逐 Unit 校对词库。


## 本次词库更新
- 已从原来的少量示例词扩充到约 709 条结构化词条。
- 覆盖：三、四、五、六年级；每个年级上册、下册；Unit 1-6。
- 保留短语（如 `go shopping`、`take a trip`）作为可练习词条。
- 当前版本按经典 PEP（三年级起点）教材体系整理。

### 版本提醒
人民教育出版社目前同时存在不同阶段的 PEP 教材版本；2024 新教材与经典版在单元主题和词汇上有明显变化。正式作为孩子日常课本同步工具时，应先确认手中课本的出版/教材版本。


## 在线学习版新增功能
- 智能复习：优先抽取掌握度较低的词。
- 拼写训练：中文 → 英文输入，支持回车提交。
- 听音拼写：浏览器英文语音朗读后输入英文。
- 选择题：英文 → 中文四选一。
- 错题强化：错题可单独进入拼写/选择练习。
- 每日目标：5/10/20/30/50 题可选。
- 连续学习天数。
- 学习统计：已学习、已掌握、答题次数、近 7 天。
- 简单间隔复习：答对后逐步延长下一次复习间隔，答错后优先重新出现。
- 数据保存在浏览器 LocalStorage，无需数据库即可个人使用。

## 新旧教材
人民教育出版社说明，2024 年起的新教材对单元容量、词汇分层、语音等进行了调整；例如新版三年级上册页面采用 Greetings、School things、Toys、Friends、Drinks and fruits、Food 六个单元。旧版与新版不能直接混用。
